# EXPERIMENTS

Use this directory for active or completed business validation tests.

Each experiment should be self-contained and named with a number plus short topic.

Example:

```text
001-roofing-landing-page-service/
```

## Active Experiments

- `001-roofing-landing-page-service/`: AI-assisted storm damage and roof inspection landing page service for roofing contractors.
- `002-restaurant-landing-page-service/`: AI-assisted focused campaign landing page service for local restaurants.

## Expected Experiment Files

- `README.md`: quick guide to the experiment.
- `plan.md`: goal, scope, checklist, and decision rules.
- `research.md`: experiment-specific research notes.
- `validation.md`: validation process, metrics, and outcomes.
- `offer.md`: offer, buyer, pricing, and boundaries.
- `finances.md`: pricing, costs, and revenue scenarios.
- `product/`: product specs, copy, wireframes, demos, or build assets.
- `marketing/`: outreach, prospect tracking, scripts, and launch notes.
- `assets/`: experiment-specific images, brand files, or media.

## Rule

Only create experiment folders for ideas selected for validation.
