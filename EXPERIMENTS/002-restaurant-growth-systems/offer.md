# Offer

## Working Offer

```text
I review a local restaurant's public customer journey, identify the biggest visible gap, and implement one focused improvement: a better inquiry flow, cleaner ordering path, campaign page, promo automation, review workflow, or retention campaign.
```

## Package

```text
Setup price: $750 for one focused implementation module
Optional monthly add-on: $250/month
```

## Setup Includes

- Public customer journey review.
- One prioritized recommendation.
- One fixed-scope implementation module.
- Copy, structure, links, and workflow guidance needed for that module.
- Basic tracking recommendations.
- One revision round.

## Optional Monthly Add-On

- Small copy, link, or workflow edits.
- Seasonal campaign swaps.
- Weekly specials or promo support.
- Email/SMS sequence maintenance.
- Review workflow updates.
- Tracking review.
- Simple monthly performance summary.
- One recommended next test.

## Solution Modules

### Catering / Private Dining Inquiry Page

Best for restaurants with group dining, event space, catering menus, party trays, or private rooms.

Possible deliverables:

- inquiry page,
- short form/question set,
- FAQ,
- package highlights,
- tracking plan.

### Restaurant Email / SMS Promo Automation

Best for restaurants with repeat customers, events, specials, loyalty lists, or inactive email/SMS tools.

Possible deliverables:

- welcome sequence,
- weekly promo template,
- birthday offer sequence,
- lapsed-guest reactivation sequence,
- approval workflow.

### Google Business Profile + Menu / Order Link Cleanup

Best for restaurants where guests may hit confusing or outdated links before they ever reach the website.

Possible deliverables:

- link audit,
- recommended primary links,
- menu/order/reservation link cleanup plan,
- UTM tracking guidance,
- owner checklist.

### Online Ordering Conversion Audit

Best for takeout-heavy restaurants with confusing ordering paths, too many competing links, or poor mobile flow.

Possible deliverables:

- order journey review,
- friction list,
- prioritized fixes,
- button/copy recommendations,
- tracking plan.

### Event / Private Dining Lead Tracking System

Best for restaurants with event inquiries but no simple way to track source, status, follow-up, and value.

Possible deliverables:

- inquiry fields,
- status values,
- spreadsheet or CRM-lite tracker,
- follow-up script,
- monthly review process.

### Review Response + Reputation Workflow

Best for restaurants with active reviews and inconsistent owner responses.

Possible deliverables:

- response templates,
- escalation rules,
- weekly review checklist,
- positive review reuse guidance,
- reply tone guide.

### Weekly Specials Content Automation

Best for restaurants that post specials manually and inconsistently.

Possible deliverables:

- weekly content template,
- approval checklist,
- Google/Instagram/email reuse plan,
- lightweight automation spec.

### Birthday / Loyalty Reactivation Campaign

Best for restaurants with email/SMS lists or loyalty tools that are underused.

Possible deliverables:

- birthday offer flow,
- lapsed-guest sequence,
- copy templates,
- tracking recommendations.

### Website / Menu Cleanup Package

Best for restaurants with outdated pages, buried menus, unclear hours, weak CTAs, or poor mobile scannability.

Possible deliverables:

- menu page cleanup,
- CTA cleanup,
- hours/location cleanup,
- private dining/catering link placement,
- mobile readability improvements.

### Focused Landing / Campaign Page

Best when one offer needs a clean link from Google, Instagram, email, QR cards, or existing site traffic.

Possible deliverables:

- campaign page,
- guest-facing copy,
- CTA,
- FAQ,
- tracking plan.

## Positioning

Sell this as a practical recommendation and implementation sprint, not as a generic website redesign or a one-size-fits-all marketing package.

Core message:

```text
Your restaurant already has food, service, and local proof. I look for the clearest gap in the guest journey and fix one focused piece first.
```

## Primary Buyer

Independent restaurants that:

- Have public proof of active demand or local reputation.
- Have a visible customer journey issue in their website, Google profile, ordering flow, reservations, catering, events, reviews, content, or retention.
- Can make decisions without a large corporate marketing process.
- Have a reachable owner, manager, events contact, catering contact, or marketing contact.

## Avoid

- Restaurants with no visible contact path.
- Businesses with no clear operational capacity to handle the recommended action.
- National chains or franchise locations with locked-down marketing.
- Businesses asking for guaranteed reservations, orders, revenue, rankings, ratings, or ad results.
- Work that requires deep POS, delivery platform, reservation platform, or CRM integration before a pilot can be useful.

## Offer Boundaries

Do not promise:

- Guaranteed reservations.
- Guaranteed orders.
- Guaranteed catering leads.
- Guaranteed event bookings.
- Guaranteed revenue.
- Guaranteed search rankings.
- Guaranteed review ratings.
- Guaranteed ad performance.

Do promise:

- A clear recommendation based on the restaurant's public customer journey.
- One focused implementation module.
- Better structure, copy, links, workflow, or tracking around the selected opportunity.
- A practical next step the owner can review before committing to anything bigger.
