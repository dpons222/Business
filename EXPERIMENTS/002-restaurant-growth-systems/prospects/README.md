# Prospects

Use this folder for future restaurant-specific prospect packages.

For strong prospects, create:

```text
prospects/<prospect-slug>/
  README.md
  recommendation.md
  client-summary.md
  outreach-email.md
  campaign-tracking-strategy.md
```

Use:

- `recommendation.md` for internal reasoning and module selection.
- `client-summary.md` for client-facing explanation.
- `outreach-email.md` for the exact first message and follow-ups.
- `campaign-tracking-strategy.md` for how the restaurant could test the recommendation.

## Rules

- Start with the restaurant's actual public customer journey.
- Choose one recommendation category before drafting outreach.
- Use the restaurant's logo and site color direction when making visual demo content.
- Use workflow samples or tracker examples when the recommendation is operational rather than visual.
- Avoid third-person generic page copy in client-facing demo sections.
- Do not promise reservations, orders, catering leads, revenue, rankings, review ratings, or ad performance.
- Run the marketing pre-send checklist before sending outreach.
