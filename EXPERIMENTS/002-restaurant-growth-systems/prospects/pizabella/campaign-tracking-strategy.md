# Pizabella Campaign Tracking Strategy

## Pilot

```text
Restaurant Customer Journey Cleanup
```

## Responsibility Level

Level 2: cleanup plus campaign support.

The client keeps the current POS/order system. The pilot focuses on improving the public journey around that system and setting up practical review points.

## Primary Goals

- Make the public website feel complete and current.
- Make the order path easier to understand.
- Improve top menu item presentation.
- Keep public menu/order links consistent.
- Create a weekly specials workflow.
- Add basic tracking recommendations.

## Baseline To Capture

Before changes:

- Home page copy and CTA state.
- About page copy state.
- Hours page copy, phone, and address.
- Order URL and service options.
- Current public links from Facebook, Town of Woodstock, and other visible directories.
- Count of priority menu items missing useful descriptions or photos.
- Current active special.
- Current tracking setup that the owner can access.

## Recommended Tracking Signals

Track what is practical without making revenue promises:

- order button clicks from public pages,
- click-to-call clicks,
- visits to the order page,
- featured special clicks,
- menu category clicks if the platform exposes them,
- weekly special posts published,
- public link updates completed,
- owner-reported order or inquiry feedback if available.

## UTM / Link Cleanup Plan

Use one clean order URL per traffic source when possible:

```text
Website order button
Facebook profile
Google Business Profile
Town/local directory updates
Weekly special posts
QR code or printed menu if used
```

If ArrowPOS or the owner cannot support UTM tracking cleanly, document the source checklist instead of forcing fragile tracking.

## Weekly Specials Workflow

Suggested fields:

```text
special_name
short_description
price_or_offer
date_range
photo_needed
order_link
facebook_copy
google_post_copy
website_blurb
approved_by
published_date
```

## Review Rhythm

First 2 weeks:

- Verify site copy changes.
- Verify order links.
- Verify top menu item updates.
- Publish or prepare one special.

After 30 days:

- Review click/order signals available from the platform.
- Review owner feedback.
- Decide whether to continue monthly support, add review workflow, or test a catering/group order module.

## Follow-On Tests

If the cleanup is accepted, next tests should be:

1. Weekly specials content system.
2. Review response workflow.
3. Catering/group order inquiry page if the owner confirms group orders are valuable.

## Guardrails

- Do not promise increased orders, revenue, rankings, or review scores.
- Do not change POS settings without owner approval.
- Do not use unapproved photos.
- Confirm all public claims with the owner before publishing.
