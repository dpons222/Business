# Pizabella Pricing Strategy

## Recommendation

Lead with a fixed-scope paid pilot:

```text
Restaurant Customer Journey Cleanup
Setup price: $750
Optional monthly support: $250/month
```

This is a good first price because the visible work is valuable but still narrow: copy cleanup, order-path review, menu merchandising recommendations, public link cleanup, specials workflow, and tracking guidance. It avoids sounding like a full website rebuild or an open-ended marketing retainer.

## Package Structure

### Pilot: Customer Journey Cleanup

Price:

```text
$750 one-time setup
```

Includes:

- Home, About, and Hours copy recommendations.
- Order, phone, pickup, delivery, and dine-in CTA cleanup.
- Online ordering flow audit.
- Top-seller menu description/photo recommendation list.
- Public menu/order link cleanup plan.
- Weekly specials workflow template.
- Basic tracking recommendations.
- One revision pass after owner feedback.

Does not include:

- POS migration.
- Paid ads.
- Full website rebuild.
- Photography.
- Ongoing social media management.
- Deep ArrowPOS configuration changes without owner/platform access.
- Guaranteed orders, revenue, rankings, review ratings, or delivery volume.

## Optional Monthly Support

Price:

```text
$250/month
```

Best positioned as:

```text
Monthly menu, specials, link, and tracking support.
```

Includes:

- One monthly specials update workflow.
- Small menu copy updates.
- Public order/menu link checks.
- Basic tracking review.
- One short monthly recommendation note.

Good reasons to offer monthly support:

- Pizabella already has an active order system.
- Specials can become a repeatable monthly workflow.
- Menu descriptions/photos may need staged cleanup.
- Public links and listings can drift over time.

## Follow-On Add-Ons

Use these only after the first pilot or if the owner asks for that specific help.

### Review/Reputation Workflow

Suggested price:

```text
$300 setup or included in month two support
```

Includes:

- Review response templates.
- Weekly review checklist.
- Positive review reuse guidance.
- Escalation rules for unhappy guests.

### Catering / Group Order Page

Suggested price:

```text
$500-$750 setup
```

Use only if the owner confirms group orders or catering are a priority.

Includes:

- Group order/catering page or inquiry flow.
- Menu/package highlights.
- Date, time, guest count, pickup/delivery, and contact fields.
- Tracking recommendations.

### Menu Merchandising Sprint

Suggested price:

```text
$350-$500 setup
```

Use if they want to focus only on the online menu.

Includes:

- Top 15-25 item description recommendations.
- Photo priority list.
- Category/order recommendations.
- Featured special recommendations.

## Discount Strategy

Do not discount the pilot by default.

Acceptable validation discount:

```text
$500 first pilot price
```

Only use this if:

- Pizabella is interested but price-sensitive.
- We can keep scope tight.
- We can use the finished work as a case study or proof asset with permission.

If discounted, remove or reduce scope:

- No monthly tracking review included.
- One revision pass only.
- Top 10-15 menu item recommendations instead of 15-25.
- Specials workflow template only, not ongoing specials support.

## Pricing Rationale

The price should be framed around practical owner value:

- The order system is already active.
- The public site has visible cleanup needs.
- The menu has many items, so prioritization matters.
- Public links should send guests to the right place.
- Specials and tracking can create ongoing monthly support work.

This should not be framed as a generic website design fee. It is a cleanup and conversion-support sprint around the existing ordering system.

## Proposal Language

Use:

```text
I would keep the first step fixed-scope: $750 to clean up the public customer journey around your existing ordering system. That would cover the Home/About/Hours copy, order path review, top menu item recommendations, public order-link cleanup, a weekly specials workflow, and basic tracking recommendations.
```

If monthly support is discussed:

```text
After that, monthly support would be optional. If useful, I could keep the specials/menu/link checks going for $250/month.
```

## Guardrails

- Do not charge for outcomes we cannot control.
- Do not bundle in paid ads or platform subscriptions.
- Do not promise order growth, revenue growth, review growth, or ranking improvement.
- Do not include open-ended revisions.
- Do not start implementation until the owner confirms access, approval path, and exact scope.
