# Solution Modules

This file defines the flexible module menu for the restaurant experiment.

## 1. Catering / Private Dining Inquiry Page

Best for:

- group dining,
- catering,
- private rooms,
- event spaces,
- party trays,
- office lunches.

Deliverables:

- focused inquiry page or section,
- short inquiry question set,
- FAQ,
- package/menu highlights,
- tracking plan.

Signals to track:

- inquiry clicks,
- form submissions,
- calls,
- booked consults if the restaurant shares them.

## 2. Restaurant Email / SMS Promo Automation

Best for:

- repeat-customer restaurants,
- weekly specials,
- events,
- loyalty lists,
- underused email or SMS tools.

Deliverables:

- promo template,
- welcome sequence,
- birthday offer sequence,
- lapsed-guest sequence,
- approval checklist.

Signals to track:

- sends,
- opens if available,
- clicks,
- redemptions if the restaurant can track them.

## 3. Google Business Profile + Menu / Order Link Cleanup

Best for:

- outdated public links,
- confusing menu or ordering paths,
- restaurants relying on Google traffic.

Deliverables:

- link audit,
- recommended primary links,
- menu/order/reservation link cleanup plan,
- UTM guidance,
- owner checklist.

Signals to track:

- profile clicks,
- website clicks,
- order/reservation link clicks where available.

## 4. Online Ordering Conversion Audit

Best for:

- takeout-heavy restaurants,
- confusing order buttons,
- too many handoffs,
- poor mobile ordering clarity.

Deliverables:

- order journey review,
- friction list,
- prioritized fixes,
- CTA copy recommendations,
- tracking plan.

Signals to track:

- order link clicks,
- ordering page visits,
- completed orders only if the restaurant can provide data.

## 5. Event / Private Dining Lead Tracking System

Best for:

- event inquiries,
- private dining,
- catering follow-up,
- group booking pipeline visibility.

Deliverables:

- inquiry field list,
- status values,
- spreadsheet or CRM-lite tracker,
- follow-up scripts,
- review cadence.

Signals to track:

- inquiries,
- response time,
- follow-ups sent,
- booked events if the restaurant shares them.

## 6. Review Response + Reputation Workflow

Best for:

- active Google/Yelp review flow,
- inconsistent owner replies,
- recurring review themes.

Deliverables:

- response templates,
- tone guide,
- escalation rules,
- weekly review checklist,
- positive review reuse guidance.

Signals to track:

- reviews responded to,
- response time,
- recurring complaint themes,
- positive quotes captured for approved reuse.

## 7. Weekly Specials Content Automation

Best for:

- recurring specials,
- inconsistent posting,
- restaurants that need one update reused across channels.

Deliverables:

- weekly specials input template,
- reusable post/email/Google copy formats,
- approval checklist,
- lightweight automation spec.

Signals to track:

- posts published,
- link clicks,
- replies,
- offer redemptions if trackable.

## 8. Birthday / Loyalty Reactivation Campaign

Best for:

- repeat-visit restaurants,
- loyalty programs,
- email/SMS lists,
- lapsed guest opportunities.

Deliverables:

- birthday message,
- lapsed guest sequence,
- simple offer framing,
- list hygiene checklist,
- tracking recommendations.

Signals to track:

- sends,
- clicks,
- redemptions if trackable,
- returning guests if the restaurant can report it.

## 9. Website / Menu Cleanup Package

Best for:

- unclear menu access,
- outdated hours,
- buried CTAs,
- weak mobile scannability,
- confusing location/contact information.

Deliverables:

- prioritized cleanup list,
- revised copy blocks,
- CTA/link placement recommendations,
- mobile readability guidance,
- implementation checklist.

Signals to track:

- menu clicks,
- call clicks,
- order/reservation clicks,
- contact form submissions.

## 10. Focused Landing / Campaign Page

Best for:

- one campaign,
- one seasonal event,
- one high-value offer,
- clear traffic source from Google, Instagram, email, QR, or ads.

Deliverables:

- campaign page,
- guest-facing copy,
- CTA,
- FAQ,
- tracking plan.

Signals to track:

- visits,
- CTA clicks,
- calls,
- inquiries,
- order or reservation clicks.
