# Solution Copy Deck

Use these blocks as starting points. Replace placeholders and remove anything that does not fit the restaurant.

## Personalized Recommendation

```text
Observed: [Restaurant Name] has [specific public strength], but [specific guest journey gap] is harder to act on than it should be.

Recommendation: Start with [solution module] so guests can [desired action] with less confusion.

First step: I would keep this narrow and build [specific deliverable] before touching anything larger.
```


## Review Workflow

```text
The opportunity is to make review responses consistent, fast, and aligned with the restaurant's voice.
```

Response principles:

```text

Reference the specific experience when appropriate.
Invite direct follow-up for service issues.
Do not argue publicly.
Keep the tone human and concise.
```
