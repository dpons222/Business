# Personalized Recommendations

Use this folder for future light recommendation or demo briefs for specific restaurant prospects.

Do not create deeply customized unpaid work before interest. Before a reply, keep each brief focused on:

- restaurant name,
- source reviewed,
- one observed customer journey issue,
- one recommendation category,
- one suggested first module,
- one reason it fits,
- quick brand color match only if a visual demo is useful.

For workflow-heavy modules, prefer a short process outline or tracker sample instead of a full visual page demo.

- `pizabella-audit-preview.html`: visual audit preview for the Pizabella customer journey cleanup.
