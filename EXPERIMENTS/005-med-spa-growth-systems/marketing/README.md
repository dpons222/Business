# Marketing

Use this folder for med spa prospect research, outreach, validation tracking, and batch review.

## Pre-Send Checklist

- Verify business name, location, website, and contact method.
- Re-check the treatment page, booking path, package page, or proof mentioned in the draft.
- Confirm the message avoids medical claims and guaranteed outcomes.
- Confirm the recommendation is based on public evidence.
- Confirm tracker status and next follow-up date.
