# Finances

## Pricing Test

```text
Setup price: $1,000
Optional add-on: $300/month
```

## Revenue Scenarios

```text
1 setup sale:
$1,000 one-time

1 setup sale + add-on:
$1,000 setup + $300/month
$4,600 first-year revenue if retained for 12 months

3 setup sales:
$3,000 one-time

3 setup sales + add-ons:
$3,000 setup + $900/month
$13,800 first-year revenue if retained for 12 months

5 setup sales + add-ons:
$5,000 setup + $1,500/month
$23,000 first-year revenue if retained for 12 months
```

## Estimated Costs

```text
Domain: $10-$20/year if a demo domain is needed
Landing page hosting: $0-$25/month depending on stack
Email/outreach tools: $0-$50/month for first test
Design/assets: $0-$50 initially
Paid ads: $0 for validation phase
```

## Financial Assumption

This experiment should be validated primarily through direct outreach, not paid ads. The first goal is to see if roofers show buying interest before investing in a polished business site or paid acquisition.

## Pricing Notes

- The $1,000 setup price is intentionally simple for validation.
- The $300/month add-on is positioned as lightweight optimization and maintenance, not full marketing management.
- Avoid custom scope creep unless the pilot is paid.
