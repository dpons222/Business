# Charger Roofing Personalized Demo Brief

## Purpose

Create a lightweight Level 1 personalized demo for Charger Roofing before outreach.

This is not a full custom build. It uses public business details and the reusable roofing landing page system so Charger can quickly understand the page direction.

## Demo Direction

Use a short assessment flow rather than another brochure-style page:

```text
1. What happened? Hail, leak, wind, or not sure.
2. Which signs do you see?
3. What is the property ZIP/contact info?
4. Show the recommended next step and request the free inspection.
```

## Recommended Page Angle

Create a direct San Antonio hail inspection assessment that keeps Charger Roofing's current offer but makes the inspection request feel more immediate after a storm. The page should reduce reading before action, help homeowners self-identify obvious damage signs, and use public trust cues carefully without promising leads, rankings, revenue, or insurance outcomes.
