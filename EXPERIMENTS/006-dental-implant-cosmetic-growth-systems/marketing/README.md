# Marketing

Use this folder for dental implant and cosmetic dentistry prospect research, outreach, validation tracking, and batch review.

## Pre-Send Checklist

- Verify practice name, location, website, and contact method.
- Re-check the treatment page, booking path, financing page, or proof mentioned in the draft.
- Confirm the message avoids treatment claims and guaranteed outcomes.
- Confirm tracker status and next follow-up date.
