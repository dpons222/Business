# Offer

## Working Offer

```text
I build focused restaurant campaign pages that make one important action easier to take: request catering, book private dining, plan a group meal, reserve for a seasonal event, or start an online order.
```

## Package

```text
Setup price: $750
Optional monthly add-on: $250/month
```

## Setup Includes

- One focused landing page for a selected restaurant action.
- Conversion-focused copy based on the restaurant's existing menu, brand, and public information.
- Clear primary CTA, such as request catering, reserve a table, call, order online, or ask about private dining.
- Sections for menu highlights, occasion fit, trust signals, location, hours, and frequently asked questions.
- Mobile-first layout guidance.
- Basic tracking recommendations.
- One revision round.

## Optional Monthly Add-On

- Small copy or section edits.
- Seasonal campaign swaps.
- CTA and link checks.
- Tracking review.
- Simple monthly performance summary.
- Recommendations for one next test.

## Positioning

Sell this as a focused campaign asset, not a generic restaurant website redesign.

Core message:

```text
Your restaurant already has food, service, and local proof. The page should make one high-value action easy to understand and easy to take.
```

## Primary Buyer

Independent restaurants that:

- Have a strong visual brand, menu, or local reputation.
- Offer catering, private dining, large-party bookings, events, seasonal meals, gift cards, or takeout.
- Have a website where the relevant action is buried, unclear, or split across platforms.
- Use Instagram, Google Business Profile, email, local ads, QR cards, or events to send traffic somewhere.
- Can make a decision without a large corporate marketing process.

## Avoid

- Restaurants with no clear offer beyond normal dine-in service.
- National chains or franchise locations with locked-down marketing.
- Businesses with no public menu, phone, address, or contact path.
- Restaurants asking for guaranteed reservations, orders, revenue, rankings, or ad results.
- Restaurants where the desired action depends entirely on a third-party platform that cannot be linked or tracked.

## Offer Boundaries

Do not promise:

- Guaranteed reservations.
- Guaranteed orders.
- Guaranteed catering leads.
- Guaranteed event bookings.
- Guaranteed revenue.
- Guaranteed search rankings.
- Guaranteed ad performance.

Do promise:

- A clearer page focused on one action.
- Better structure for mobile visitors.
- Stronger presentation of existing menu, brand, and trust signals.
- A simpler path to call, reserve, order, or inquire.
- Basic tracking recommendations so the owner can judge whether the campaign is worth continuing.

## First Offer Variants

### Private Dining / Event Inquiry Page

Best for restaurants with private rooms, group seating, event menus, or party packages.

Primary CTA:

```text
Request private dining details
```

### Catering Inquiry Page

Best for restaurants with office catering, party trays, family meals, or custom menus.

Primary CTA:

```text
Request catering availability
```

### Seasonal Reservation Page

Best for brunch, holidays, tasting menus, patio season, game days, or limited-time dining events.

Primary CTA:

```text
Reserve for this event
```

### Takeout / Online Ordering Page

Best for restaurants with strong takeout economics and confusing order paths.

Primary CTA:

```text
Start an order
```
