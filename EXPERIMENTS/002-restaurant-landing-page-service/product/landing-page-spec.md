# Landing Page Spec

## Goal

Create a focused restaurant landing page that helps a guest take one action:

- request catering,
- ask about private dining,
- plan a group meal,
- reserve for a seasonal event,
- order online,
- buy a gift card,
- call the restaurant.

## Required Page Inputs

```text
restaurantName
cityState
cuisineOrConcept
targetOffer
primaryCtaLabel
primaryCtaUrl
secondaryCtaLabel
secondaryCtaUrl
phone
address
hoursSummary
website
brandColors
brandPaletteSource
menuHighlights
occasionUseCases
trustSignals
faqItems
```

## Recommended Sections

1. Header with logo/name, primary CTA, phone, and optional reservation/order link.
2. Hero focused on the target action.
3. Menu or package highlights.
4. Occasion fit, such as office lunches, birthdays, private dinners, holidays, or family meals.
5. How it works.
6. Trust and local proof.
7. Location, hours, and contact.
8. FAQ.
9. Final CTA.

## CTA Rules

Use one primary CTA per page.

Examples:

```text
Request catering availability
Ask about private dining
Reserve for this event
Start an order
Call the restaurant
Buy a gift card
```

Secondary CTAs are allowed only when they do not compete with the primary action.

## Tracking Notes

For pilots, track practical actions:

- page visits,
- primary CTA clicks,
- click-to-call clicks,
- order link clicks,
- reservation link clicks,
- inquiry submissions,
- traffic source when possible.

Do not promise that tracking will prove revenue unless the restaurant shares downstream order, reservation, or sales data.

## Design Notes

- Match the restaurant's logo and site colors.
- Use mobile-first layout.
- Make menu highlights easy to scan.
- Keep copy direct and guest-facing.
- Avoid generic third-person analysis such as "the restaurant's public page says."
- Write as the restaurant speaking to guests once the page is client-facing.
