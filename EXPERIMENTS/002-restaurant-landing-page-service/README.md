# 002 Restaurant Landing Page Service

Validation experiment for an AI-assisted landing page service aimed at local restaurants.

## Core Test

```text
Will local restaurants pay for a focused landing page that improves one measurable action, such as catering inquiries, private dining requests, group bookings, seasonal reservations, or online ordering clicks?
```

## Current Offer

```text
Primary offer: Restaurant campaign landing page for private dining, catering, events, or seasonal offers
Target market: Independent local restaurants with visible brand assets and a specific high-value offer
Price test: $750 setup
Optional add-on: $250/month
Validation target: 20 qualified prospects
Success signal: 1 paid pilot, 2 serious sales calls, or 3-5 positive replies
Timebox: 14 days
```

## Guardrails

- Do not promise guaranteed reservations, orders, catering leads, revenue, search rankings, or ad performance.
- Keep unpaid personalized demos light until there is interest.
- Match restaurant logo and site colors when creating a demo.
- Use public restaurant facts carefully, and do not imply endorsement before the restaurant approves the work.
- Before sending any outreach, run the marketing pre-send checklist in `marketing/README.md`.
