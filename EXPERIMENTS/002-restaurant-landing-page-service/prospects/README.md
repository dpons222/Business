# Prospects

Use this folder for future restaurant-specific prospect packages.

For strong prospects, create:

```text
prospects/<prospect-slug>/
  README.md
  recommendation.md
  client-summary.md
  outreach-email.md
  campaign-tracking-strategy.md
```

Use:

- `recommendation.md` for internal reasoning.
- `client-summary.md` for client-facing explanation.
- `outreach-email.md` for the exact first message and follow-ups.
- `campaign-tracking-strategy.md` for how the restaurant could test the page.

## Rules

- Keep prospect notes specific to public facts.
- Use the restaurant's logo and site color direction when making demo content.
- Avoid third-person generic page copy in client-facing demo sections.
- Do not promise reservations, orders, catering leads, revenue, rankings, or ad performance.
- Run the marketing pre-send checklist before sending outreach.
