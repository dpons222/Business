# Marketing

Use this folder for remodeler prospect research, outreach, validation tracking, and batch review.

## Files

- `prospect-tracker.csv`: active prospect tracker.
- `prospect-tracker.md`: tracker field guide and status values.
- `outreach-script.md`: first message and follow-ups.
- `discovery-call-questions.md`: questions for interested remodelers.

## Pre-Send Checklist

- Verify company name, service area, website, and contact method.
- Re-check the project page, portfolio, consultation flow, or proof mentioned in the draft.
- Confirm the recommendation avoids guaranteed leads, projects, revenue, rankings, reviews, or ads.
- Confirm tracker status and next follow-up date.
