# IDEAS

Use this directory for business ideas before they become active experiments.

## Files

- `backlog.md`: raw and scored ideas.
- `idea-template.md`: reusable template for new ideas.
- `scoring-questionnaire.md`: default preferences and scoring weights.
- `archived.md`: ideas that are not worth pursuing right now.

## Rule

Do not create an experiment folder until an idea has been scored, reviewed, and selected for validation.
