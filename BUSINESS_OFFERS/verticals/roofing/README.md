# Roofing Vertical

The roofing vertical is the first active service offer under `BUSINESS_OFFERS/`.

## Current Offer

```text
Focused storm-response / roof inspection landing pages for roofing companies.
```

## Target Customer

Roofing companies in storm-prone markets that already offer free inspections, roof checkups, storm damage inspections, or insurance-related roof assessments.

## Core Problem

Many roofing sites already have the right offer, but the page is often broad, educational, or visually basic. A focused landing page can make the inspection request path clearer for storm-season traffic.
