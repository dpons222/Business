# Website

Planning area for the owner's public credibility site.

## Purpose

The first website should make outreach feel safer and more credible. It does not need to look like a large agency.

The site should answer:

- Who is this?
- What do they build?
- Who is the current offer for?
- Can I see an example?
- How do I reply or contact them?

## Recommended First Sitemap

```text
/
/roofers
/work
/contact
```

## Page Intent

- `/`: short credibility page for the business and current focus.
- `/roofers`: roofing-specific offer page for storm-response inspection landing pages.
- `/work`: selected demo concepts and project-style summaries.
- `/contact`: simple contact path.

## First Site Constraint

Do not build a broad multi-industry agency site yet.

The first version should support the active roofing offer. Add pages for plumbing, dental, real estate, or other verticals only after those offers are actively tested.
