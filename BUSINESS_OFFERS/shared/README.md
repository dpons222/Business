# Shared Offer Assets

Reusable assets for selling and operating service offers across validated verticals.

Use this folder for material that should not be locked inside one vertical:

- pricing patterns,
- discovery questions,
- objection handling,
- outreach principles,
- pilot structures,
- tracking language,
- scope boundaries.

## Current Shared Rule

Lead with a small, specific pilot. Avoid broad retainers or vague "AI solutions" positioning until a vertical has evidence.
