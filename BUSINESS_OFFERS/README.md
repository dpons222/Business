# Business Offers

This directory holds the operating offer layer for the business: the owner's positioning, credibility site planning, reusable sales assets, and vertical-specific service offers.

It is separate from `EXPERIMENTS/`.

- `EXPERIMENTS/` is for validation tests, prospect research, demo builds, and campaign evidence.
- `BUSINESS_OFFERS/` is for the reusable business presence and offers that can be sold across validated verticals.

## Current Focus

```text
Primary vertical: roofing
Primary offer: focused storm-response / roof inspection landing pages
Current proof asset: Charger Roofing demo concept
Current goal: support credible manual outreach without overbuilding a full agency brand
```

## Structure

```text
brand/
website/
shared/
verticals/
  roofing/
```

- `brand/`: positioning, credibility copy, name/domain ideas, and public-facing tone.
- `website/`: sitemap, copy drafts, and future public website planning.
- `shared/`: reusable pricing, outreach, objections, and sales/process assets.
- `verticals/`: one folder per actively tested industry vertical.

## Vertical Rule

Only create a vertical folder when there is a real test to support.

Do not create placeholder folders for plumbing, dental, real estate, HVAC, or other categories until there is a specific offer, prospect list, or validation plan.
