# Launch Checklist

Use this checklist when an experiment is ready for a public test or launch.

## Offer

- [ ] Customer is clearly defined.
- [ ] Problem or desired outcome is clearly stated.
- [ ] Offer is specific.
- [ ] Pricing or monetization path is documented.
- [ ] Call to action is clear.

## Product Or Service

- [ ] Minimum useful version is ready.
- [ ] Core user flow works.
- [ ] Delivery process is documented.
- [ ] Support expectations are realistic.
- [ ] Risks and limitations are documented.

## Marketing

- [ ] Primary distribution channel is selected.
- [ ] Launch copy is drafted.
- [ ] Visual or media assets are ready if needed.
- [ ] Tracking links or analytics are prepared if needed.
- [ ] Follow-up process is documented.

## Validation

- [ ] Success metric is defined.
- [ ] Test duration is defined.
- [ ] Evidence will be recorded in the experiment folder.
- [ ] Decision rule is defined: continue, change, or archive.

## Operations

- [ ] Required accounts, tools, or credentials are available.
- [ ] Costs are known.
- [ ] Manual steps are documented.
- [ ] Automation opportunities are noted for later.
